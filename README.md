# tools
Useful html tools built with Gemini or Claude Code.

- [从微信文章链接提取信息转换格式](https://meichiny.github.io/tools/wechat-extract.html)：提取标题、日期，按照固定格式转换输出结果
- [朋友圈文字防折叠](https://meichiny.github.io/tools/wechat-moments-unfurl.html)：通过零宽字符注入、同形字符替换等方式，使长文字在朋友圈发布时不被折叠
- [Markdown 学习工坊](https://meichiny.github.io/tools/markdown-tutor.html)：边学边练的 Markdown 入门工具——实时预览、语法卡片对照学习、闯关挑战，100% 本地离线
