③ URL 传参说明（部署到线上后可用）

点击展开 · 参数优先级：d / data > text > url > 锚点 #
参数示例说明
d / data?d=JTNDaGVhZCUzRQ推荐。结构化文本的 Base64URL 编码（UTF-8），可避免换行与特殊字符导致的链接错乱
text / t?text=%3C%E5%90%8D%E5%AD%97%3E...结构化文本原文，需做 URL encode
url / src?url=https://a.com/a.txt远端文本地址，页面自动拉取（目标服务需允许跨域 CORS）
以下为可选控制参数
name?name=10月筛查导出文件名前缀，最终为 名称_日期.xlsx
sheet?sheet=名单Excel 工作表标签名
fields / cols?fields=名字,电话,备注指定列顺序（逗号或顿号分隔），未列出的字段仍会追加在后面
hide?hide=备注,是否测听隐藏指定列，不参与导出
index?index=0设为 0 时不加序号列，默认 1
split?split=0设为 0 时关闭「重复字段自动拆分新记录」，默认 1
auto?auto=1载入并解析成功后自动触发一次下载，适合从其它系统一键跳转导出
文本较长时建议放锚点：页面地址#<名字>张三</名字>…，锚点内容不会发送到服务器。 d 参数需自行对原文做 UTF-8 Base64 编码，再把 + 换成 -、/ 换成 _、去掉结尾 =。
